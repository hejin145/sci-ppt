# 正式幻灯片制作

## 从论文到叙事

先读取正文、方法、图题、表注及与主结论相关的补充材料。对每个拟上屏的主张核对原文段落、图号或表号，记录样本或模型、比较组、指标、单位、样本量与效应。置信区间、显著性、统计检验和误差条含义按原文出现情况保留。多篇文献先确定主论文，其他论文按其具体作用提供背景、方法依据或独立证据。

用「研究缺口、科学问题、设计如何回答、关键证据、机制解释、下一步」串起全篇。每页优先传达一个判断，结果页标题在证据允许时直接写发现。以下是默认页序，可按读到的证据调整各区篇幅。

| 页 | 中英标题与内容 |
|---|---|
| 01 | **组会文献汇报 · Journal Club**。论文主题、英文原题及已知的汇报信息。 |
| 02 | **文献概览 · Paper Overview**。作者、期刊、年份、DOI 和研究焦点。 |
| 03 | **研究背景 · Background**。已知证据、尚未解决的问题和研究场景。 |
| 04 | **科学问题 · Research Question**。核心问题，以及论文明确提出的假设或比较。 |
| 05 | **研究设计 · Study Design**。流程图展现样本或数据、分组或比较、结局和验证环节。 |
| 06 | **研究方法 · Methods**。解释关键方法回答了什么，保留理解结果所需的对照和统计信息。 |
| 07 | **关键结果一 · Key Result I**。主结果及其最直接的图表证据。 |
| 08 | **关键结果二 · Key Result II**。验证、补充结果或影响解释的次要发现。 |
| 09 | **机制模型 · Mechanism**。画出证据支持的关系，标识假设或推断。机制资料有限时，改为概念模型或证据关系图。 |
| 10 | **研究创新 · Contributions**。归纳本研究新增的方法、证据或认识。 |
| 11 | **讨论与局限 · Discussion**。具体说明适用范围、关键局限和可检验的替代解释。 |
| 12 | **总结与展望 · Takeaways**。用简短结论回答科学问题，并提出由论文和局限支持的后续研究方向。 |

对综述、方法论文和观察研究，沿用证据叙事，按实际内容调整分组、干预、机制等栏目。人体、动物、体外、模拟或不同队列的结果写清适用对象。将关联、实验支持的因果关系和作者推断分别用对应措辞表达。

## 图表和机制图

- 原图复用时标出论文及对应 `Fig. 2B` 或 `Table 1` 等位置，保留图例、坐标、误差条和单位。重绘尽量使用原文表格或可用数据，写明「据 Fig. 2B 重绘」等来源。若在必要时从图上读取数值，标为近似读数并按原图精度呈现。
- 使用真实数据渲染结果图，把生成式图像工具用于封面插图、示意素材和风格预览。数据不完整时可改用带来源的原图、定性归纳或证据表。效应量、样本量及统计量以可核对的来源为准。
- 设计流程、机制或概念模型时，尽量用可编辑形状、连接线和文字。实线、虚线或标签的含义写在图例中。对相关性和因果性用清晰标签，并在图旁标注文献依据。

## 交付前核对

以已选风格为基准完成封面和统一版式。保留每页密度、字体层级及主要图表的可读性，尽可能让标题、注释、图表和流程对象保持可编辑。使用当前演示文稿工具的渲染或预览逐页检查投影效果，核对页数、比例、中英文字体、图表单位、来源、文本溢出及图层遮挡。交付用户可打开的演示文稿及适用的下载方式，并简要说明资料缺口或影响使用的交付限制。
